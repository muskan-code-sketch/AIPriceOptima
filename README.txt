# AI Price Optima 📊🤖

## 📌 Project Overview

**AI Price Optima** is a machine learning-based project designed to analyze and predict product pricing using an Amazon dataset (`Amazon.csv`). The project focuses on extracting meaningful insights through data analysis, visualization, and predictive modeling using advanced algorithms like **XGBoost** and **LightGBM**.

---

## 🎯 Objectives

* Perform **data preprocessing and cleaning** on raw Amazon dataset
* Conduct **exploratory data analysis (EDA)**
* Create **visualizations** (heatmaps, plots, correlations)
* Build and evaluate **machine learning models**
* Compare model performance and accuracy

---

## 📂 Dataset

* **File Used:** `Amazon.csv` from kaggle.com
---

## 🛠️ Technologies & Libraries Used

* **Programming Language:** Python
* **Libraries:**

  * Pandas (Data manipulation)
  * NumPy (Numerical operations)
  * Matplotlib & Seaborn (Visualization)
  * Scikit-learn (Preprocessing & evaluation)
  * XGBoost (Gradient boosting model)
  * LightGBM (Efficient boosting framework)

---

## 🔍 Project Workflow

### 1. Data Preprocessing

* Handled missing values
* Removed duplicates
* Encoded categorical variables
* Feature selection and transformation

### 2. Exploratory Data Analysis (EDA)

* Statistical summary of dataset
* Identified patterns and trends
* Correlation analysis

### 3. Data Visualization

* Heatmaps for correlation
* Bar plots, histograms, scatter plots
* Distribution analysis

### 4. Model Building

* Applied:

  * **XGBoost**
  * **LightGBM**
* Split data into training and testing sets

### 5. Model Evaluation

* Evaluated using accuracy and performance metrics
* Compared both models

---

## 📈 Results

* Both **XGBoost** and **LightGBM** were implemented successfully
* Model accuracy was relatively in the range of 93 to 97 percentage, indicating:

  * Possible need for better feature engineering
  * Dataset limitations
  * Need for hyperparameter tuning
